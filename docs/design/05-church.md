# 05 — Church

## Conversion & organisation
- `DECIDED` Converting provinces and building church organisation is a core building goal:
  **bishopric + bishop's palace in every province**.
- `DECIDED` Surviving post-imperial bishoprics may exist at game start.

## Clergy
- `DECIDED` Clergy is a **headcount pool**, not map units.

## Church tech tree
- `DECIDED` Civ-like church tech tree: **know** the tech (points spent on research) + **build it
  locally**.
- `PROPOSED` "Know" costs Piety points; "build" costs local turns, resources and materials.
- Every node is described with Opportunity / Constraint / Actor.

## The Church as an actor
- `DECIDED` The Church is an **autonomous actor**.
- `PROPOSED` Stats: Wealth, Influence, Satisfaction. Gives benefits (stability, tech boosts) and
  escalating demands at thresholds (via event engine, 08).

## Church ownership (historical basis: Eigenkirche)
- `PROPOSED` Each church building has an owner field (king, bishop, village, noble kindred, town).
- `PROPOSED` A **reform event** (proprietary church → patronage rights / ius patronatus) as an
  era-defining mechanic.
- `PROPOSED` Kindred monasteries feed the count's rootedness meter (02).
- `PROPOSED` Cathedral building as a multi-turn project.

## Reference (not a game plan)
Church was both taxpayer and tax collector (tithe). Useful later for the economy (06).
